# 🐍 Repositorio de Proyectos en Python

Este repositorio forma parte de mi camino de formación como desarrollador backend y estudiante de Licenciatura en Informática. 
Contenedor de mis primeros proyectos, prácticas de lógica algorítmica, Programación Orientada a Objetos (POO) y control de versiones con Git.

---

## 📂 Proyectos Incluidos

Cada proyecto se encuentra organizado en su propia carpeta con su respectivo código fuente modularizado:

| Proyecto | Descripción | Conceptos Aplicados | Archivo Principal |
| :--- | :--- | :--- | :--- |
| **Calculadora Simple** | Aplicación de consola que permite realizar operaciones matemáticas básicas con validación de entradas. | Estructuras de control, funciones (`def`), bucles `while`, manejo de excepciones (`try-except`) y atajos de teclado (`KeyboardInterrupt`). | `Calculadora Simple/calculadora.py` |
| **Gestor de Tareas** | Sistema modular de administración de pendientes con menús interactivos, conteo de estados y persistencia en memoria mediante listas y diccionarios. | POO / Estructuras de datos (`list[dict]`), tipado estático (*type hints*), funciones y validación robusta de opciones. | `Gestor de Tareas/gestor_tareas.py` |
